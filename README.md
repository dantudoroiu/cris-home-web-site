# Cris Home Holiday Inn Website

This project is a simple, modern one-page website for a holiday inn. It is built with plain HTML, CSS, and JavaScript.

## Project goal
Create a welcoming online presence for the hotel with:
- a hero section
- room highlights
- amenities
- contact information
- a simple booking form

## Main files
- index.html: page structure and content
- styles.css: visual design and layout
- script.js: small interactive behavior such as the contact form message

## How to preview locally
Open index.html in a browser, or use a live preview extension such as Live Server in VS Code.
